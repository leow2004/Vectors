# Vectors
Understanding vector math, and how it relates to modern day computing. 
Cyber Threat Vector Proximity & Alignment Analyzer
This utility leverages geometric vector analysis to map and correlate threat actor indicators. By computing the Euclidean distance and Cosine Similarity between numerical threat behavior vectors, the engine identifies overlapping operational patterns. When two threat profiles exhibit high cosine similarity (approaching 1.00), the system generates automated analyst assumptions indicating a strong probability of shared or coordinated attack infrastructure. This mathematical alignment assists Security Operation Centers (SOCs) and Threat Intelligence teams in identifying unified, multi-pronged campaigns that might otherwise appear as isolated incidents.
